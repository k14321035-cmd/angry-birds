# angry-birds
# 🎮 Angry Birds Game Prototype

A mobile-optimized Angry Birds game prototype built with **Phaser 3** and **JavaScript**.

## 🎯 Features

✨ **Gameplay**
- Launch red birds to destroy green enemies
- Physics-based collisions and gravity
- Multiple levels of difficulty
- Score system with points tracking
- Limited birds per round (5 birds)

🎮 **Controls**
- **Desktop/Mobile**: Tap and drag to aim, release to launch
- **Touch Friendly**: Fully responsive on all devices
- **Keyboard**: Works on any device with a browser

📱 **Mobile Optimized**
- Responsive design for all screen sizes
- Touch controls optimized for phones and tablets
- High-performance rendering
- Auto-scaling graphics

## 🚀 Quick Start

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Click "TAP TO PLAY" to start
4. Drag and release to launch birds
5. Destroy all green pigs to win!
